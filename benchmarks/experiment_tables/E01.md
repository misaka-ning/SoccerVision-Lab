# E01 足球单类别微调实验表

整理日期：2026-10-22。训练日期：2026-10-19；后续 Orin 数据注明其来源场次。

| 项目 | 内容、产出与结论 |
| --- | --- |
| 实验定位 | 提高足球检测能力，建立后续结构实验与部署比较的单类别基线。 |
| 初始化来源 | E00 原始 YOLO26s 权重；E01 训练后的基线保存为 `baseline/E1_baseline.pt`。 |
| 实验内容 | 将80类输出改为 `nc=1`、`0=football`；兼容权重迁移后进行全网络微调。主体架构、多尺度连接与两套检测分支保留，没有缩窄模块。 |
| 权重迁移 | 迁移696/708个状态张量，重建两套检测分支、三个尺度的12个最终分类张量。 |
| 训练数据 | 冻结 v1 Train 4,346张；Val 1,223张，用于验证及最佳checkpoint选择。 |
| 训练条件 | RTX 4060；640、batch=8、seed=42、AdamW、lr0=0.001、AMP、cosine、不冻结；最多100 epochs、patience=30。 |
| 实际训练 | 完成74轮，最佳epoch为44，训练耗时66.07分钟。 |
| 模型验证 | 独立重载确认 `nc=1`、`names={0: football}`；one-to-many原始输出 `[1,5,8400]`，Val输出类别为0。 |
| 模型总参数量 | 9,948,638；相比 E00 减少61,146。 |
| 独立 Val 条件 | 1,223张、855个框、410张无球；CPU单线程、batch=4、FP32、640方形letterbox；候选下限0.001、conf=0.25、匹配IoU=0.5、NMS IoU=0.7、max_det=300。 |
| 精度结果 | mAP50=96.0161%；mAP75=87.0652%；mAP50–95=78.5508%。 |
| 相对 E00 的 AP 变化 | mAP50增加35.7843个百分点；mAP50–95增加23.1399个百分点。 |
| 工作点结果 | conf=0.25：Precision=94.9275%，Recall=91.9298%，F1=93.4046%；TP/FP/FN=786/42/69。 |
| 无球误报与代价 | 19/410张，4.6341%；相比 E00 的0/410增加。Recall增加48.5380个百分点，但Precision下降4.5363个百分点。 |
| 开发机速度 | RTX 4060 FP32、batch=1的 CUDA event 均值约6.6115 ms；与 E00 分布高度重叠，约0.03 ms均值差未认定为明显加速。 |
| 后续 Orin Engine 基线 | E03对原有 E01 Engine 三轮交错复测：mean=28.13498 ms/batch2，P95=28.17087 ms；25W、GPU上限408 MHz、动态时钟。该值是Engine执行时间。 |
| 历史完整系统基线 | E03报告核验的历史三轮 E01 系统数据：16.490 Hz，cycle均值60.444 ms；仅用于同场次 E01/E02 配对比较。 |
| 主要产出 | 单类别best/last及恢复训练权重；训练配置、日志、逐轮CSV；类别/权重迁移检查；独立Val指标、预测和图表；E00/E01公平对照及复现说明。 |
| 实验结论 | 显著改善该 Val 上的 AP 与足球召回，建立可复现的单类别基线；低工作阈值误报增加。训练与类别数共同改变，不能把全部收益单独归因于减少类别数。 |
| 比较边界 | 只有seed=42；这里使用历史CPU Val记录。不同设备评估耗时不能作为模型加速证据，Val成绩不作为独立Test成绩。 |
