# E00 原模型基线实验表

整理日期：2026-10-22。

| 项目 | 内容、产出与结论 |
| --- | --- |
| 实验定位 | 建立原始模型的足球检测基线，作为 E01 微调前的参照。 |
| 模型起点 | 已有 YOLO26s 原始80类权重，当前保存为 `baseline/E0_original_best.pt`；历史记录中的 `baseline/original_best.pt` 为原路径。 |
| 实验内容 | 保持原模型结构与权重，选择原类别32 `sports ball`，映射为数据类别0 `football`，完成全量 Val 检测评估。 |
| 本轮训练情况 | 未新增训练；本实验评估已有原始权重。 |
| 评估数据 | 冻结 v1 Val 共1,223张，有球813张、确认无球410张、足球框855个；属于 Val 成绩。 |
| 评估条件 | CPU单线程、batch=4、FP32、640方形 letterbox、无TTA；候选下限0.001、工作conf=0.25、匹配IoU=0.5、NMS IoU=0.7、max_det=300。 |
| 模型总参数量 | 10,009,784；与 E01 使用同一历史参数统计口径。 |
| 精度结果 | mAP50=60.2318%；mAP75=59.2731%；mAP50–95=55.4108%。 |
| 工作点结果 | conf=0.25：Precision=99.4638%，Recall=43.3918%，F1=60.4235%；TP/FP/FN=371/2/484。 |
| 无球误报 | 0/410张，0%；只表示本次 Val 中没有无球图片误报，不代表所有场景都无误报。 |
| 速度记录 | 历史 RTX 4060 FP32、batch=1、640输入的 CUDA event 均值约6.6431 ms；不含预处理、传输和NMS，不作为 Orin 完整系统成绩。 |
| 主要产出 | 原始权重引用与输入指纹；`evaluation/metrics.json`、`REPORT.md`、全量候选预测、逐图匹配/误报明细、PR/置信度/分场景图表。 |
| 实验结论 | 固定conf=0.25时，预测较保守：Precision高，但Recall只有43.3918%、FN为484；足球漏检是后续 E01 微调需要改善的主要问题。 |
| 后续作用 | 固定原始模型和数据作为 E01 的公平参照；不将其开发机推理计时外推为机器人频率。 |
