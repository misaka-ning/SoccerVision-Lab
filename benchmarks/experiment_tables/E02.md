# E02 第19层结构缩窄实验表

整理日期：2026-10-22。恢复训练日期：2026-10-20；独立 Val 日期：2026-10-21。实机量化结果引用后续 E03 归档。

| 项目 | 内容、产出与结论 |
| --- | --- |
| 实验定位 | 以较小改动验证指定层内部通道缩窄、权重迁移和恢复训练流程，并检查是否改善实际部署性能。 |
| 初始化来源 | **已完成微调的 E01 权重** `baseline/E1_baseline.pt`；从 E01 建立新的优化器进行恢复训练。 |
| 实验内容 | 只修改全局第19层C3k2，即Head第9条顶层定义：`e=0.5→0.4375`；scale=s时隐藏通道128→112。 |
| 保持的接口 | 第19层输入384通道、输出256×40×40（640输入）；足球单类别、输入尺寸、P3/P4/P5检测连接和双分支定义保留。 |
| 选择第19层的理由 | 先做范围较小、便于对照的实验；当时没有证据证明该层最冗余或可带来最大加速。 |
| 权重迁移 | 分支感知的确定性前缀通道映射，处理split、concat、内部支路、残差和BN；不是基于L1或重要性排序的剪枝。 |
| 正确性准备 | 完成迁移测试、保存重载、官方模型重建和合成前向检查。P3仅在恢复训练前与源 E01 逐值相同；全网络恢复训练后不承诺其数值不变。 |
| 训练条件 | 冻结Train 4,346张、Val 1,223张；RTX 4060；640、batch=8、seed=42、AdamW lr0=0.001、AMP；最多100 epochs、patience=30，沿用 E01 配方。 |
| 实际训练 | 用户完成78轮恢复训练，最佳epoch为48；逐轮CSV累计4033.39秒，约67.22分钟。 |
| 参数变化 | 9,948,638→9,881,630，减少67,008，约**0.674%**；第19层隐藏通道减少12.5%。 |
| 独立 Val 条件 | 同一1,223张、855框、410张无球；CUDA FP32、batch=4、640方形letterbox、候选下限0.001、工作conf=0.45、NMS IoU=0.7、max_det=300。 |
| 精度结果 | mAP50=95.9545%；mAP75=88.3125%；mAP50–95=78.7770%。 |
| 相对 E01 的 AP 变化 | 对照保留的 E01 历史CPU Val：mAP50减少0.0617个百分点，mAP75增加1.2473个百分点，mAP50–95增加0.2262个百分点；整体接近，并非完全相同。 |
| 工作点结果 | conf=0.45：Precision=99.1150%，Recall=91.6959%，F1=95.2612%；TP/FP/FN=784/7/71；无球误报3/410张，0.7317%。 |
| 精度比较边界 | E01工作conf=0.25、E02为0.45，不直接比较工作点收益；E01历史评估在CPU、E02在CUDA。AP数据内容与核心算法一致，但不是同环境配对复测；额外恢复训练与结构效应尚未分离，原结构同预算control只有准备记录。 |
| 原有 Engine 三轮实测 | E03归档：E01 mean=28.13498 ms/batch2，E02 mean=28.27537 ms/batch2，E02增加0.14039 ms（约0.499%）；E02 P95=28.33907 ms、P99=28.35631 ms。 |
| 历史完整系统三轮对照 | E03报告已核验：E01为16.490 Hz、cycle 60.444 ms；E02为16.450 Hz、cycle 60.585 ms。没有系统吞吐收益，不与 E03 新增的单轮锚点混作前后提升。 |
| L19后续剖析 | 原有Engine三次profile合计：E01为1.36850 ms，E02为1.47933 ms，局部增加约8.10%；属于带profiler的模块范围，不能与正常Engine计时混加。 |
| 实机测量条件 | Jetson Orin NX 16GB、25W、GPU上限408 MHz、动态时钟；TensorRT FP16计算、FP32 I/O，固定双目batch=2。数值与具体构建/设备条件绑定。 |
| 主要产出 | 窄结构YAML、分支感知迁移工具和检查；独立初始化及训练配置；恢复训练best/last、日志和CSV；独立Val指标与图表；后续E03中的Engine/系统对照和L19诊断。 |
| 实验结论 | 完成结构缩窄与恢复训练流程验证，总参数量减少且整体 Val AP 接近 E01；**所测试方案未取得可测量的推理延迟或系统吞吐收益，未有效改善当前部署条件下的实时性能。** |
| 保留与后续 | E01继续作为性能对照基线，E02作为实验候选保留。不能把本结果推广为所有结构缩窄都无效；后续选层应依据实际执行耗时。 |
