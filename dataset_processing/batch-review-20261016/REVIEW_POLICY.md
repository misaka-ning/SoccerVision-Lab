# 后续批次审核口径

生效：2026-10-16，第5批及之后；依据用户当次明确指示。已审核的前4批保留用户结果。

- **遮挡（Occluded）**：包括手、脚、腿、机器人、物体等明确前景遮挡；足球被画面边缘截断（包括只露半个球）也标1。只是贴近而未覆盖仍为0。
- **无球（No Ball）**：按最终label框数分类。预审后label为空则标1，保留或补上球框则标0。不确定是否可见或无法准确画框时可保留人工处理状态，但label仍为空的图片按本项目新口径标1，备注说明待补框/待确认原因。
- **小目标（Small）**：按完整球体尺度折算到图像长边672后约40像素判断；大球被挡或被裁切后露出的残片不自动算小目标。
- **运动模糊（Blurred）**：足球或相机有可辨方向性拖影；仅像素低、对焦软化或脚运动不自动算。
- 上述四项可重叠，均不属于时全0。新补球框是待审候选，只画当前帧可见范围，保留多球图中其他真球。
- 新口径只改变场景分类判定，不把未审核样本自动设为已审核；预审的球框和场景两项均待用户复查。

机器可读配置：[review-policy.json](./review-policy.json)。每批提案汇总时验证最终label框数和No Ball一致。旧历史报告中的不同口径保留作历史记录，以本文件为后续标准。
