## 人工复查

全部1000张已固定为20组，每组50张，包含全部307张疑点，左右目同帧同组。名单不会随审核进度改变。

```bash
/home/misaka/workspace/script/review_football_batch.sh 3 --group 1
```

顶部“前50张 / 后50张”连续翻页；点击图片进入单张修改，保存后按G返回。场景只显示为1的中文名称，其余留空。可将命令的组号换为2–20从指定组继续；`3 --groups`查看每组label和场景待审数。

若先看疑点可用 `3 --priority --gallery`，它不能替代全量1000张的复查。逐图理由见 [precheck.csv](./precheck.csv)；完整提案及原生证据路径见 [proposals.json](./proposals.json)。

## 判定口径

小目标以完整球尺度折算到图像长边672后约40像素判断，不能把大球露出的小残片算小目标。真实前景覆盖才算遮挡，接触和画面裁切不直接算。足球或相机方向性拖影算运动模糊，低分辨率柔化与单独鞋移动不自动算。无球必须逐图检查，不依据空label、模型漏检或另一目推断。

墙脚小足球可见圆形外缘和黑白球纹；另一场景墙脚扁平白片经native放大及二次检查，更符合纸片/杂物，不凭白色小物一律补球框。若球身份或定位仍不确定，保留可见性/球框疑点。
