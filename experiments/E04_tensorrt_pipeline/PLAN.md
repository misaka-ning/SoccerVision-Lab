区分 Engine CUDA event、传输、后处理方法墙钟、完整检测器墙钟、系统 cycle、processing/publish Hz、读取完成至发布 P50/P95/P99。每批为左右目两张图；不把图片吞吐当双目 Hz，不将异步 GPU 与 CPU 墙钟相加。
