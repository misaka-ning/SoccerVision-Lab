# E04 当前组合性能的人工测试条件

相机固定、机器人静止、球也静止。此次比较链路开销，不要求移动相机或球，不作运动跟踪压力测试。

1. 开始前由用户手动确认球在左右目共同视野中、两目均可稳定检测；若只确认原画面有人眼可见的球，应如实说明。球无遮挡、不过度模糊，远离边缘；不以改阈值/距离门槛迁就场景。
2. 退出自己启动的检测/相机预览，正式Viser=false；不停止运控、ROS0或其他用户程序。冲突时测试退出并保留日志。
3. 30组（detector15+system15），每组100预热+60秒，预计约40–45分钟。虽先离线后现场，整个测试期间保持球、相机、机器人、照明和背景不变；人不遮挡。变化应记录大致时间并反馈。
4. 不改模型/Engine、输入/阈值/NMS/top-k、定位/跟踪/发布配置、功耗或时钟；不同时启动其他benchmark/重负载或第二份本测试。
5. 无有球预检、预览脚本或自动有球率门槛。完成后从左右候选、原packet测量/跟踪有效标志、coasting及帧关联审查适用范围。没有物理距离真值；source读取时间戳不是曝光时刻，不能作图像年龄。

当前对照为R0/A2/R4/R5，不再重跑A1等单项。原模型/源码/配置/版本保护、GPU锁、ROS87+localhost、timeout和R0漂移保护继续生效。具体唯一当前入口见NEXT_RUN.md，可以关闭SSH，不需持续观察。

此前两份visualization.yaml因预览设true导致首次有球启动失败，已在phase3独立目录备份后恢复冻结false，hash一致；记录VISUALIZATION_RESTORATION.json保留。正式测试勿重新启用Viser。
