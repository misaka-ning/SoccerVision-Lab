# 足球视频数据集整理

把用户提供的视频整理成可追溯、可人工审核的单目图片、YOLO 球框和场景 metadata。完整执行提帧、去重、视觉分类、自动识别足球并写入 label、校验及合并；整理图片后必须继续完成自动标注，不需要用户再单独要求。只运行提帧 helper 不算完成任务。

## 输入

- **必填：本地视频路径**，可为一个文件或明确列出的多个文件。接受调用后的裸路径或自然语言里的路径，例如 `$football-dataset-curation /绝对路径/录像.avi`。路径含空格时使用引号。未提供路径时先询问；不自行挑选“最新视频”。路径不存在或读取失败时报告具体问题，已有视频能处理则继续。
- 可选：目标数据集路径、有效起止时间、单目/水平双目布局、模型路径、采样频率、划分方案。显式参数优先于下面的本机默认值。
- 本机默认目标为 `/home/misaka/workspace/datasets`。已确认的机器人水平双目录像分别保存 left/right，使用同一源帧编号；未知布局先看实际画面，不能仅凭宽高比切成双目。
- 代表帧默认约 **2 fps**，额外保留短暂遮挡、明显模糊、小球变化；无需为了这个默认值询问用户。新片段默认加入 train，保留已有 val/test；创建新数据集时按来源片段分组划分并说明方案。
- 这是本地数据整理技能。SSH 下载、服务重启、远端删除及原视频物理剪辑只有用户另行提出时才执行。不要写入历史密码或把之前的机器地址当作授权。

## 工作流

1. **检查源素材。** 记录绝对路径、SHA256、分辨率、帧率、帧数、编码及有效范围，查看头/中/尾代表画面，确认没有烧录的检测框或文字。有原始 MJPEG AVI 和二次编码 MP4 时优先原始 AVI；容器名称本身不代表画质。若只有带框视频，先寻找明确对应的干净源，无法取得则说明限制，不能涂掉框后冒充原始训练图。
2. **建立独立暂存目录。** 本机默认将暂存图、过程报告与审核快照放在 `/home/misaka/workspace/dataset_processing` 下，保持目标根目录为 `images/`、`labels/`、`metadata.csv`、`dataset.yaml`。将原视频视为只读。长时间静止、重复或无球段可以先筛选有效时间区间，保留有代表性的真实负样本和困难瞬间。物理剪辑及 JSONL 对齐规则、helper 参数见 [视频与去重](references/video-and-dedup.md)。
3. **原生提帧和相邻去重。** 运行 `scripts/prepare_frames.py --video <路径> --output <新暂存目录> --layout stereo|mono`。helper 从已确认干净的源输出原生 PNG、源帧映射、去重组和预览；它不移除原图内容、不判断有无球、不生成类别或 label。检查被压缩的时间段，必要时用源帧索引 `--keep-frames` 补回困难瞬间，或给 `--rois` 防止静止背景掩盖球的变化。输出原生像素，训练图不缩放、不加框/水印。
4. **跨视频及已有数据去重。** 精确哈希用于完全相同图片，感知哈希只用于找候选，再比对实际画面及球的位置/遮挡/模糊。对保留图片清单筛选，不删除原视频或已有人工整理的样本。左右目配对和相邻时序归为同一划分，防止泄漏。详见 [视频与去重](references/video-and-dedup.md)。
5. **逐图视觉分类。** 先读 [分类与标注规范](references/schema-and-review.md)。逐张检查最终保留图，尤其没有检测候选的图和灰色背景球；缩略图难辨时看原生图/放大局部。四项是独立场景标记，普通样本全 0。
6. **整理后自动识别足球并写 label。** 对提帧、去重和分类后的每张新保留图片执行足球识别，默认自动完成，不等待额外指令。有用户指定或本地实际可用的 YOLO 模型时先推理，可结合对应录像 JSONL 辅助查漏；没有可用模型时由助手逐图视觉识别并预标注，不因此跳过标注。按真实 `model.names` 找到足球类别并映射到数据集 class 0；每个可见足球写一个归一化 YOLO 框到 `labels/<split>/<图片stem>.txt`，多个球写多行。所有新自动框标为待人工审核。**视觉确认没有足球时也必须创建同名、零字节的 `.txt` label 文件**，同时设置 `No Ball=1`、`annotation_status=negative_confirmed`；不能只写 CSV 或依赖检测工具默认省略空 label。模型没有检测到球不等于无球，需逐图复核。确实无法判断或无法可靠画框时保留待审核/待补框状态并记录原因，不能假造框或用空文件冒充确认负样本。
7. **合并并校验。** 保留已有图片、label 字节、split、CSV 人工修改和未知列；追加本次数据，不用旧快照覆盖当前 metadata。先备份本次涉及文件并记录基线，校验暂存内容，检查基线未被审核工具改动，再逐文件原子写入、最后替换 CSV；发生错误按本次清单回滚。运行 `scripts/validate_dataset.py --dataset <路径>`，并核对本次所有可可靠标注的图片均有对应 label、确认无球图片的 label 全部存在且为零字节；未能完成识别/补框的例外必须列入待审核清单。生成本次来源/保留/排除原因和待审核清单，metadata.csv 为实时权威来源。
8. **交付。** 报告本次/总图片数、各 split、四项数量（可重叠）、自动框/待补框/已确认负样本数量、非空/空/缺失 label 文件数、输出和审核清单路径。本机审核工具可用时给出 `/home/misaka/workspace/script/dataset-reviewer/review_dataset.sh --dataset <路径>`。待审核框或缺失 label 的数据不能称为已审核、可直接训练；用户需要训练时另行生成只含确认样本的子集。

## 执行环境

helper 需要 Python 3、OpenCV、NumPy；优先使用实际可用的环境。本机可尝试 `/opt/VisionStudio/runtime/bin/python`。不要默认系统 `python3` 已包含这些库，不修改共享 runtime 或自动安装依赖。`validate_dataset.py` 仅用标准库。参考文件记录脚本输入输出与具体数据规范。

## 调用示例

```text
$football-dataset-curation /home/misaka/temp/recording.avi
$football-dataset-curation 视频="/绝对路径/录像.avi" 目标="/绝对路径/football_dataset" 水平双目，有效范围=00:00–27:00
$football-dataset-curation 处理 /路径/片段1.avi 和 /路径/片段2.avi，去重后补充到 /路径/football_dataset，保留困难瞬间
```
