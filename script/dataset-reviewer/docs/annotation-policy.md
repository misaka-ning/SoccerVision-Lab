# 足球可见性与不确定样本标注规范

规范版本：1；适用于 train、val、test。单帧检测只使用当前帧可辨认的足球视觉证据。看不清足球不等于没有足球，模型未检出也不等于无球。

## 判断规则

| 当前帧情况 | 处理 | 普通检测训练与标准评测 |
| --- | --- | --- |
| 可识别且可可靠定位 | 标注足球；小目标、模糊、遮挡分别记录 Small、Blurred、Occluded | 场景和 label 均审核通过后可用 |
| 可识别，但框的位置或大小不可靠 | uncertain_bbox | 排除 |
| 当前帧没有足够证据，只能用前后帧推断 | temporal_only | 排除 |
| 足球完全遮挡，没有可见像素，时序可确认存在 | fully_occluded | 排除，不作为无球负样本 |
| 严重模糊，无法辨认 | severe_blur | 排除 |
| 严重遮挡，无法辨认 | severe_occlusion | 排除 |
| 原因尚待查明 | uncertain | 排除 |
| 明确不存在需标注的可见足球，且无未解决的疑似目标 | No Ball=1，空 label，经人工通过成为 negative_confirmed | 场景审核通过后可用 |

不确定性是样本审核状态，不是新的 YOLO 类别。遇到无法可靠标注的疑似目标，即使同一图片还有其他已标注足球，也暂时排除整张图片，避免把未标注区域当成背景。

## 框的统一口径

本规范采用**当前帧可见部分的紧致外接矩形**：遮挡样本只框可见足球像素，不用前后帧补全不可见轮廓；运动模糊仍须能可靠识别目标及其可见范围。仅靠猜测才能确定边界时标记 uncertain_bbox。所有 split 使用相同口径。

现有标签不会自动转换为该口径。已有遮挡框应人工复核，确认采用相同定义后再导出；不要把可见框与推断完整框混用。

## 保留、复核和恢复

标记 uncertain 时，保留原始图片、现有 label、拍摄场次、视频路径、帧号、左右目及其他附加元数据；No Ball 清为0，场景和 label 均设为待复核。不创建空 label，不补推断框，不删除图片。旧框只作参考，不代表可用检测真值。

审核工具将原因写入 annotation_status；metadata 的每次实际修改前保存完整备份，备份文件名含 UTC 时间和唯一编号，可追溯状态变化。已有 label_review_note 保留。来源字段缺失时，导出也无法恢复缺失的视频索引，需维护者从采集记录补齐。

获得新的可靠证据后，点击「重新复核」，进入待修正状态；核对当前帧、必要时修改 label，再分别确认 label 和场景。重新复核本身不把图片加入训练集。仍然无法可靠标注的图片继续保留为 uncertain。

## 检测集与时序集

正式普通检测实验使用「导出审核数据集」生成的新目录及其中的 dataset.yaml。程序只收录场景和 label 都已审核通过的有效正样本与明确负样本。未审核样本同样不进入训练、验证和测试。

不确定样本复制到独立 uncertain/<原因>/<原split>/images/，旧 label 复制到 reference_labels/，不会作为普通 YOLO labels。原 split 和来源信息保存在 uncertain/metadata.csv 中，便于复核后回到原集合，避免随意重新划分造成数据泄漏。

每次审核变化后生成一个新的导出版本。export-summary.txt 保存规范版本、生成时间、源 metadata SHA256 和各集合数量。既有导出是固定快照，不随后续审核自动更新；不能继续用过期快照。

困难但可辨认的图像可用于检测鲁棒性评测；单帧不可辨认、时序可推断的图像另建跟踪专项协议，区分 observed_bbox、inferred_bbox、tracking_state。当前工具不生成轨迹或推断框；reference_labels 也不自动获得上述语义。

## 删除条件

仅文件损坏、无保留价值的完全重复、无部署或研究价值、严重失真且无可利用信息时考虑删除。正常采集的严重模糊或遮挡帧保留研究价值。审核工具不自动删除样本。
