# 足球数据集审核工具

使用 C++17 / Qt 6.8 的本地界面，逐张核对图片、YOLO 标签和困难场景分类。支持在图片上手工修改检测框，保存 `labels/` 中的标签文件及数据集根目录中的 `metadata.csv`；图片保持只读。

## 启动与环境

启动入口为产品根目录的 `review_dataset.sh`。完整环境要求、默认数据集查找规则和构建命令见 [产品 README](../README.md#快速开始)；数据字段要求见 [数据约定](data-format.md)。

```bash
/home/misaka/workspace/script/dataset-reviewer/review_dataset.sh
/home/misaka/workspace/script/dataset-reviewer/review_dataset.sh --dataset /你的/数据集
```

从界面点击「打开数据集…」可切换根目录。修改前先确认路径栏指向目标数据集。

## 场景分类

四个分类复选框为「Small · 小目标」「Occluded · 遮挡」「Blurred · 运动模糊」「No Ball · 无球」，互相独立，可同时勾选多个类别。`1` / `2` / `3` / `4` 切换对应项，「全部置0」清除四项；在搜索框输入时不会触发数字快捷键。

修改后点「保存审核」或用 `Ctrl+S` 保存；按 `Enter` 执行「确认分类并下一张」，清除当前 `scene_review_required`、保存并进入下一张。左右方向键切换前后图片，切换时保留尚未保存的修改。「场景仍需复核」只对应场景分类；确认场景分类不会通过 label 审核。

## label 人工审核

筛选「待label审核」可集中查看 `label_review_required=1`、`auto_label_needs_review` 或 `needs_manual_bbox_annotation` 的图片。橙色框是尚待人工审核的候选，绿色框是保留的原标注；当 label 已通过审核时，框显示为绿色。`preserved_box_count` 指定标签文件开头保留的框数，`auto_box_count` 记录自动生成的候选数量。两项计数是来源记录，界面不会在人工修正标签后改写它们。

逐张检查球的位置、框的范围、漏检及误检，再点击「label审核通过」或按 **`A`**。该操作会保存当前审核结果，并设置 `label_review_required=0`：非空有效标签对应 `reviewed_annotation`；空标签只有在人工勾选 `No Ball=1` 后才能成为 `negative_confirmed`。缺少 label、格式错误、空标签但 `No Ball=0` 均不能通过。`A` 不自动切到下一张，在搜索框和文本输入框中输入时不会触发审核。

需要补充或修正框时，点击「手工修改label…」或双击图片，打开图形编辑窗口：

- 点击框选中，拖动框移动，拖动四角调整大小。
- 点击「新增框」后在图片上拖动绘制；新框默认类别为 `0`。
- 选中后可修改类别及归一化中心坐标、宽高，或点击「删除选中框」。
- 滚轮缩放，右键或中键拖动平移；「还原本次修改」恢复打开窗口时的框。
- 点击「保存 label 并待审核」写入文件并保存当前 metadata 修改，设置 `label_review_required=1` 和 `annotation_status=needs_manual_bbox_annotation`。核对后按 `A` 审核通过。取消或关闭编辑窗口会丢弃本次框修改。

缺少 label 时可直接新增框并保存；删除所有框并保存会创建空 label，仍需勾选 `No Ball=1` 才能审核通过。原 label 有格式错误时，窗口会提示：保存将用当前有效框替换全部文件内容，需补齐遗漏的框。编辑窗口内的修改不触发主窗口的审核快捷键。

也可点击「label需修正」仅标记待修正，或用「打开label文件」在外部文本编辑器修正并保存，再「重新加载label」。每行使用标准 YOLO 格式：`class_id x_center y_center width height`，坐标归一化至 0–1，宽高必须大于 0。

审核通过绑定当前显示的标签文件 SHA256；若外部编辑使内容变化，程序先重新加载并拒绝本次通过，必须再次人工核对和点击。保存前也会检查已通过的标签是否变化。打开、浏览、确认场景分类或保存不会自动把候选框视为已审核标注。

有球框时 `No Ball` 必须为0才能通过。右侧复核说明显示本次建议、可见性不确定和保留人工分类的冲突，供你决定修正哪个字段。完全遮挡而无法可靠定位的图片不生成猜测框，其缺失 label 和复核标记保留，确认后再人工补框或创建空负样本 label。

用 `B` 显示或隐藏检测框，`F` 让图片适应窗口；「放大检测框」用于检查小球细节。筛选还支持小目标、遮挡、运动模糊、无球、四项全0、待场景复核及缺少 label。旧 CSV 没有 `label_review_required` 时仍可审核原有四项分类，label 审核和图形编辑按钮会禁用。

## 保存与备份

保存前在数据集 `.metadata-review-backups/` 中备份原 CSV，再以原子替换方式写入。图片、split、来源计数、未知附加列等只读元数据会被保留。只有明确的 label 审核操作能改变 label 审核字段。

手工修改 label 时，原文件的完整字节备份到 `.label-review-backups/<split>/`，然后以原子替换方式写入。保存前检查文件是否仍与打开编辑窗口时一致；外部修改会阻止覆盖。为保证修改后的框不会沿用旧的「已通过」标记，先保存待审核状态，再替换 label；若 label 写入失败，原文件保持不变，待审核状态可能已保存，界面会提示。新建 label 没有原文件备份。

程序检查 CSV 是否已被其他程序修改，遇到冲突停止保存并保留当前编辑。关闭或切换数据集时如有未保存修改，请按界面提示处理；不要同时用多个程序编辑同一 CSV。

## 快捷键速查

| 快捷键 | 操作 |
| --- | --- |
| `1` / `2` / `3` / `4` | 切换 Small / Occluded / Blurred / No Ball |
| `Ctrl+S` | 保存审核修改 |
| `Enter` | 确认场景分类并下一张 |
| `A` | label 审核通过并保存，不自动下一张 |
| `←` / `→` | 上一张 / 下一张 |
| `B` | 显示 / 隐藏检测框 |
| `F` | 图片适应窗口 |
| 双击图片 | 打开图形 label 编辑器 |

输入文本时相关字符快捷键会禁用；label 编辑窗口内的操作不触发主窗口审核快捷键。
