这是从已有数据集来源录像制作的定性演示，不能作为独立测试集精度评测。

`manifest.json` 记录源视频、模型、输出文件校验值及实际推理参数；`predictions.jsonl` 记录全部输出帧对应的源帧及检测结果；`verification.json` 记录完整视频解码、时长、帧数、阈值和片段对应核验。`preview/original_vs_E01.jpg` 为前后对照抽帧。

本次生成和核验脚本分别为 `render_video.py`、`verify_video.py`。生成脚本会拒绝覆盖已有输出，重新生成前需设置新的输出目录。
